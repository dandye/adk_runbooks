# Report Writing Guidelines

## Objective
Provide standards for writing clear, concise, and actionable security investigation reports.

## Inputs
*   `REPORT_TYPE`: Type of report (Alert, Case, PIR, Threat Hunt).

## Core Steps

1. Core Report Structure:
   * Every report must contain: Title, Executive Summary, Technical Details, Evidence, and Next Steps.

2. Writing Style Standards:
   * Use active voice, short sentences (≤20 words), and avoid unapproved jargon.

3. Evidence Presentation:
   * Present IOCs, timestamps, and log snippets in structured tables and code blocks.
